# Light

Light — открытая модульная IDE на Rust и egui для Windows, macOS и Linux.
Подключайте нужные языки и инструменты под свой проект.

## Возможности

- Языковые модули: Python, C/C++, Lisp, Assembler, HTML, CSS, Markdown, reStructuredText, Shell и Make.
- Редактор с подсветкой, автодополнением, навигацией и поиском по проекту.
- Встроенные Git, терминал и сценарии запуска.
- Linux через WSL при работе в Windows.
- Локальная история, предпросмотр документов и настраиваемые темы.

Модули устанавливаются и подключаются внутри IDE. Компиляторы и интерпретаторы настраиваются отдельно.

## English

Light is an open-source modular IDE built with Rust and egui for Windows, macOS and Linux.
Add language modules for your project, with code completion, navigation, Git, a terminal,
run scenarios, local history, document previews and customizable themes. On Windows,
Light also supports working in Linux through WSL.

Language modules are installed inside the IDE. Compilers and interpreters are configured separately.
