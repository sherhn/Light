# Language marks

SVG conversions come from https://github.com/simple-icons/simple-icons. The project's
CC0 dedication covers its contributions; original brand artwork retains its own terms.

| File | Original source and conditions |
|---|---|
| html5.svg | HTML5 Logo by W3C, https://www.w3.org/html/logo/ ; CC BY 3.0, see HTML5-CC-BY-3.0.txt. Module covers change its color, opacity and background composition. |
| css.svg | https://github.com/CSS-Next/logo.css ; CC0-1.0. |
| markdown.svg | https://github.com/dcurtis/markdown-mark ; CC0-1.0. |

C++, Python, shell, Lisp, assembler and reStructuredText cards use local typographic labels.
They do not reproduce the C++ Foundation, PSF or GNU Bash logos.
