# Themes and contrast

Settings → Appearance offers Dark, Light and Custom themes. The contrast slider (75–150%) adjusts interface text, syntax, line numbers, selections and outlines immediately. The sample shows code, selection, search highlighting and status colors before leaving Settings. The reset button returns contrast to 100%.

The standard palettes keep their quiet charcoal and off-white backgrounds, with more readable comments, line numbers and panel boundaries. Higher contrast strengthens foregrounds and outlines; lower contrast softens them. Quick View uses the same theme and contrast settings.

Custom colors remain stored exactly as entered. Contrast changes only the displayed palette, so returning to 100% restores the original color values. Switching among themes keeps both the custom color definitions and the contrast preference. Individual colors, or the full custom palette, can still be reset separately.
