## Light 1.2.0

- Independent settings for the logo inside the IDE and the window/taskbar/Dock icon.
- File dates and sizes immediately follow names and clip at the panel boundary.
- Vector language marks replace typographic placeholders on module cards.
- Project and file notes are editable Markdown documents under `.light-notes`; the Notes icon is below Modules in the left strip.
- Files open in a lightweight read-only Quick View with highlighting, search and copying. Open in IDE switches to the full environment. Windows Open With / Default Apps associations use Quick View.
- Git failures retain all stderr and stdout, including messages after WSL startup notices. Errors open a persistent, scrollable window with a button to copy the complete text. Linux and module errors are no longer shortened in their settings pages.

## Изменения

- Раздельные настройки логотипа внутри IDE и системной иконки.
- Дата и размер сразу после имени файла с обрезкой на границе панели.
- SVG-знаки модулей вместо текстовых заглушек.
- Заметки проектов и файлов в Markdown; иконка заметок под модулями слева.
- Быстрый просмотр кода с подсветкой, поиском, копированием и переходом в полную IDE. Ассоциации Windows открывают просмотрщик.
- Полный текст ошибок Git/WSL, постоянное окно с прокруткой и копированием. Предупреждение WSL о прокси больше не скрывает следующую строку с причиной сбоя Git.
