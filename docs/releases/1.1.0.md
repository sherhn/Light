## What's new in Light 1.1.0

- Official modules now live in [Light-Modules](https://github.com/sherhn/Light-Modules). The IDE installs versioned ZIP packages with archive and file SHA-256 verification, a minimum IDE version check, and validation before replacing an installed module. Installers retain a pinned offline catalog with all 17 modules.
- Local commits are now project snapshots in Local History. Saving a snapshot preserves the selected Git comparison base; comparing with a snapshot is an explicit choice.
- Overflowing editor tabs scroll with the mouse wheel and arrow buttons, and opening or activating a tab brings it into view.
- Declining the Linux suggestion is remembered across app restarts and projects. The status-bar environment selector remains available, and suggestions can be enabled again under Settings > Linux (WSL).
- Duplicate Git change markers beside the far-right scrollbar are removed; error and search markers remain.
- New coverage views, a Node.js CPU profiler with a flame graph, and a Services window for running programs and Docker containers.
- Expanded Git tools: blame, file history, stashes, cherry-pick, revert, branch comparisons and interactive rebase.
- Debugger additions: conditional breakpoints, hit counts, logpoints, disassembly and memory views.

## Изменения в Light 1.1.0

- Модули вынесены в отдельный публичный репозиторий и выпускаются ZIP-пакетами с проверкой совместимости и контрольных сумм. Все 17 модулей доступны в установщике без интернета.
- «Локальные коммиты» переименованы в снимки проекта; создание снимка сохраняет выбранную базу сравнения Git.
- Переполненная строка вкладок прокручивается; активная вкладка автоматически показывается.
- Отказ от предложения Linux запоминается. Переключение среды доступно в нижней панели, возврат предложений — в настройках Linux (WSL).
- Убраны дублирующие маркеры Git у крайнего правого скроллбара.
- Добавлены покрытие кода, профилировщик Node.js, «Сервисы», расширенные инструменты Git и новые возможности отладчика.
