## Light 1.3.0

- Signed background updates for the IDE and official modules, with independent settings and per-module opt-out. Quick View does not initialize the updater.
- IDE activation after closing all windows using the installation, isolated startup checks, retained previous versions and explicit rollback. Project files, notes, preferences and disabled module state are preserved; locally modified program files and modules are not automatically replaced.
- Debian/Ubuntu downloads the signed native package for installation through the system package manager.
- Improved dark and light palettes with more readable comments, line numbers and borders. A live 75–150% contrast slider, preview and reset work with standard and custom themes, including Quick View. Custom color definitions stay intact.

**First installation:** install this release manually if coming from 1.2 or earlier. Those versions do not contain the background updater.

## Изменения

- Подписанные фоновые обновления IDE и официальных модулей: отдельные настройки, возможность исключить любой модуль. Быстрый просмотр не запускает проверку обновлений.
- IDE обновляется после закрытия всех её окон. Проверка запуска до и после замены, сохранение предыдущей версии и откат. Проекты, заметки, настройки и состояние отключённых модулей сохраняются. Изменённые пользователем файлы программы и модули не заменяются автоматически.
- Debian/Ubuntu скачивает подписанный пакет для установки через системный менеджер пакетов.
- Улучшенные тёмная и светлая темы: читаемее комментарии, номера строк и границы. Ползунок контрастности 75–150%, предпросмотр и сброс, в том числе для собственных тем и быстрого просмотра. Заданные пользователем цвета сохраняются.

**Первый переход:** с версии 1.2 и более ранних установите этот релиз вручную — в старых версиях ещё нет фонового обновления.
