## Light 1.4.0

- File-type icons across the IDE and Quick View, with Colored, Monochrome and Standard choices in Appearance. Windows Setup adds per-type icons and Open With registration for all 79 supported extensions while preserving existing defaults.
- Tab inserts the first matching path in path fields and the Commands terminal. Completion reads folders in the background, handles spaces, Unicode, relative paths and WSL, and discards stale results. The Linux shell retains its own Tab bindings.
- File → Browse Files / Linux (WSL): view files, open them in the IDE and copy files/folders to Windows with progress, cancellation and SHA-256 verification. Originals are preserved; existing destinations, links and incompatible names are rejected.
- Run buttons beside zero-argument Lisp/Python functions, exported JavaScript functions, Docker stages, Compose services and Make/npm tasks. Existing test/coverage buttons are retained. Optional module rules allow custom languages to add actions without editing the IDE.
- Includes signed Modules 1.0.3. Updated modules were tested with the published IDE 1.3.0; their previous commands remain available.

**Updating:** Light 1.3 can download and apply this signed IDE update after closing. To add the new Windows Open With registrations to an existing installation, run the updated Setup. Portable and background updates leave Windows file associations to the installer.

## Изменения

- Значки типов файлов во всей IDE и быстром просмотре: цветные, чёрно-белые или стандартные — на странице внешнего вида. Установщик Windows добавляет значки и «Открыть с помощью» для всех 79 поддерживаемых расширений, сохраняя выбранные приложения по умолчанию.
- Tab вставляет первый подходящий путь в полях ввода и терминале команд. Чтение папок идёт в фоне; поддерживаются пробелы, Unicode, относительные пути и WSL. Устаревшие результаты не заменяют новый ввод. Терминал Linux сохраняет собственные сочетания клавиш.
- «Файл → Файлы / Linux (WSL)»: просмотр файлов, открытие в IDE и копирование файлов и папок в Windows с прогрессом, отменой и проверкой SHA-256. Исходники сохраняются; существующие файлы не заменяются. Ссылки и несовместимые имена отклоняются.
- Кнопки запуска рядом с функциями Lisp/Python без аргументов, экспортируемыми функциями JavaScript, стадиями Docker, сервисами Compose и задачами Make/npm. Кнопки тестов и покрытия сохранены. Правила для собственных языков можно добавить в модуль.
- Подписанные модули 1.0.3. Совместимость их прежних команд проверена опубликованной IDE 1.3.0.

**Обновление:** IDE 1.3 скачает подписанное обновление и применит его после закрытия. Чтобы добавить новые ассоциации файлов Windows в существующую установку, запустите новый Setup. Переносная версия и фоновое обновление оставляют регистрацию ассоциаций установщику.
